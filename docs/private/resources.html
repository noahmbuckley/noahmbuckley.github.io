Hosting options for Shiny apps (notes for future)

Three paths used here:

  1. Shinylive (static, browser-only via WebAssembly). Best for low-traffic personal use. Bundle is ~30 MB of webR runtime + your app code & data. No cold start, no server, no idle limit. Hosted on GitHub Pages alongside the rest of the site. Build: shinylive::export("path/to/app", "private/apps/<slug>"). Limitations: not every CRAN package compiles to WASM — test in a browser before committing. Used here for SDB and tracker.
  2. shinyapps.io (server-hosted). Free tier: 5 apps, 25 active hours/month. Zero rewriting, but cold-start ~30s on idle apps. Used here for Alternate Russias (already deployed, dcf in alternateRussias/app/rsconnect/).
  3. Self-hosted Shiny Server. Not used. Full control, ongoing infra cost & maintenance.

Decision rule: default to Shinylive. Switch to shinyapps.io only if the app uses a CRAN package that doesn't compile to WASM, talks to a database, or has data files large enough that bundling them in the browser bundle is prohibitive.
