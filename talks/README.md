# `talks/` — public talk decks

Source copies of decks served at `noahbuckley.me/talks/<slug>/`. `_quarto.yml`
lists `talks/**` as a resource, so a full site render copies this folder into
`docs/talks/`; when publishing, also copy into `docs/` so no render is needed.

Each deck is built in `~/Dropbox/Projects/me/talks/<talk>/` with its speaker
notes stripped (they hold private caveats), then copied here as `index.html`
plus a PDF.
